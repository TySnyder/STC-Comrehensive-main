# Task Track — Daily Timeline

Per-weekday event list for the Task Track right-rail timeline
(`TaskTrackView.tsx`, via `timelineData.ts`). One line per event:

```
- [P1|P2] HH:MM AM/PM — Event title — Optional subtitle/location
```

The `[P1]`/`[P2]` tag is optional — leave it off for an unprioritized event.
Subtitle is optional too. "Current" vs "past" vs "future" is computed
automatically from the clock, no need to mark that.

Events under "Every Day" are seeded into the timeline every day.

A `<Weekday> Priorities` section holds that day's un-timed must-dos — things
to get to today but not tied to a slot. Same `[P1]`/`[P2]` tag, no time:

```
- [P1] Priority title — Optional detail
```
