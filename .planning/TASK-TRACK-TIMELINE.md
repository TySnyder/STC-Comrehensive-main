# Task Track — Daily Timeline

Per-weekday event list for the Task Track right-rail timeline
(`TaskTrackView.tsx`, `TIMELINE_EVENTS`). One line per event:

```
- HH:MM AM/PM — Event title — Optional subtitle/location
```

Subtitle is optional — leave it off if there's nothing to add. "Current"
vs "past" vs "future" is computed automatically from the clock, no need to
mark that.

Events under the list "Every Day" are seeded into the timeline ever day.
